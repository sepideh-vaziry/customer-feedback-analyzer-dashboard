# AI Customer Feedback Analyzer - Frontend Task

## Goal
Create a React.js frontend for an AI-native SaaS platform that analyzes customer feedback.

## Backend Overview
Spring Boot backend with support for:
- OpenAI models
- Ollama models
- Provider selected through application.yaml configuration

## Initial Scope
Create only the foundation of the frontend.

### Pages
- Dashboard
- Feedback Management
- Analytics
- AI Insights
- Settings

### Layout
- Sidebar
- Header
- Main content area

### Technology
- React
- Vite
- React Router

### Future Features
- Sentiment analysis visualization
- Complaint tracking
- Feature request detection
- Churn risk monitoring
- Trend analysis
- AI summaries
- Authentication
- Organization management

Do not implement business features yet.
Only prepare a clean, scalable frontend structure.
